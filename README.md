# Nextflow Reproducible Data Science Example

This repository contains a simple Nextflow workflow example for reproducible data science using containerized processes.

## Getting Started

### Project Setup with uv

[uv](https://github.com/astral-sh/uv) is a fast Python package installer and environment manager that we'll use for dependency management.

1. **Install uv**:
   ```bash
   # On macOS/Linux
   curl -LsSf https://astral.sh/uv/install.sh | sh
   
   # On Windows
   curl -LsSf https://astral.sh/uv/install.ps1 | powershell
   ```

2. **Create a new environment and initialize the project**:
   ```bash
   # Create and activate virtual environment
   uv venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   
   # Initialize the project
   uv init
   ```

3. **Install required dependencies**:
   ```bash
   # Add data science packages
   uv add pandas numpy scikit-learn
   
   # Add Nextflow
   curl -s https://get.nextflow.io | bash
   chmod +x nextflow
   ```

4. **Create project directories**:
   ```bash
   mkdir -p data scripts docker results
   ```

### Directory Structure

```
.
├── data/
│   └── raw_data.csv             # Generated by generate_example_data.py
├── docker/
│   ├── Dockerfile.preprocess    # Docker image for preprocessing
│   └── Dockerfile.model         # Docker image for model training
├── scripts/
│   ├── preprocess.py            # Data preprocessing script
│   └── train_model.py           # Model training script
├── .venv/                       # Virtual environment created by uv
├── generate_example_data.py     # Script to generate synthetic data
├── main.nf                      # Nextflow workflow definition
├── nextflow.config              # Nextflow configuration
├── pyproject.toml               # Python project configuration (generated by uv init)
└── README.md                    # This file
```

### Building and Running

1. **Generate Example Dataset**:
   ```bash
   uv run python generate_example_data.py
   ```

2. **Build Docker Images**:
   ```bash
   docker build -t preprocess:latest -f docker/Dockerfile.preprocess .
   docker build -t model:latest -f docker/Dockerfile.model .
   ```

3. **Execute the Nextflow Pipeline**:
   ```bash
   uv run nextflow run main.nf
   ```

4. **With Custom Parameters**:
   ```bash
   uv run nextflow run main.nf --input data/raw_data.csv --outdir results --seed 123
   ```

## Workflow Steps

1. **Data Generation**: Creates synthetic customer data with features and a churn target
2. **Preprocessing**: Performs feature engineering and normalization
3. **Model Training**: Trains a RandomForest classifier and evaluates performance

## Reproducibility Features

- Fixed random seeds for data generation and model training
- Containerized processes with fixed environments
- Version-controlled workflow and scripts
- Execution reports and timelines
- Deterministic dependency management with uv
